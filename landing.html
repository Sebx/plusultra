The Problem with Cloud APIs

💰 Expensive

AWS Comprehend: $1,200/month for 1M requests. HuggingFace Inference: Similar pricing.

🔓 Privacy Leak

Your text goes to their servers. Data breaches, compliance issues, vendor tracking.

⏳ Slow

500ms–5s latency waiting for API response + network round-trip.

The Solution: Local Inference

Run the GLiClass classifier (143M params) directly on your machine.

🌐 Browser

Zero setup. Open a URL. Works offline as a PWA.

bash start-mac.sh
# Open http://localhost:8787

🐍 Python

Easy integration. Use with Django, FastAPI, Jupyter.

pip install onnxruntime
import plusultra
agent = plusultra.load("./model")

🦀 Rust

Production ready. Compiled binary, zero dependencies.

cargo build --release
./plusultra classify "Your text"

Get Started Now

🌐 Browser (Easiest)

git clone https://github.com/Sebx/plusultra
cd plusultra
bash start-mac.sh

Open http://localhost:8787

🐍 Python (Integration)

pip install onnxruntime
cd python/
python examples/basic_classification.py

🦀 Rust (Production)

cd rust/
cargo build --release
./target/release/plusultra --help
